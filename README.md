# Fundraising website

Professional fundraising website structure prepared for frontend pages, backend API development, PostgreSQL, MPesa, and card payment integrations.

## Project Structure

- `index.html` - main landing page.
- `assets/css/style.css` - shared frontend stylesheet.
- `assets/js/script.js` - shared frontend JavaScript entry point.
- `assets/images/` - image assets such as logos, campaign images, and hero images.
- `assets/icons/` - icon assets.
- `assets/fonts/` - local font files.
- `pages/` - secondary frontend pages.
- `backend/` - Node.js API scaffold for future server-side functionality.

## Backend

The backend scaffold includes Express, CORS, dotenv, and PostgreSQL client dependencies in `backend/package.json`.

```bash
cd backend
npm install
npm run dev
```
